# MacThock releases

Public downloads for [MacThock](https://macthock.com), a Mac app that plays the keyboard sound you choose as you type.

Each release attaches the signed, notarized and stapled disk image exactly as it was built, along with its SHA-256 checksum.

- Website: https://macthock.com
- Download page: https://macthock.com/download
- Support: https://macthock.com/support
- Privacy: https://macthock.com/privacy
